What I build

Change a running system in stages

Systems that already run the business cannot stop for a rewrite. I led the modernization of five related subsystems from .NET Framework to .NET 7 on a platform of more than ten interconnected subsystems, one subsystem at a time.

  • 01

    Incremental .NET migration

    .NET Framework to modern .NET, subsystem by subsystem, with shared data and integrations kept stable.

  • 02

    Architecture review and refactoring

    Where complexity comes from, which changes pay off first, and a staged path to get there.

  • 03

    SQL Server performance

    Stored procedures, triggers and spatial queries optimized where the time is actually spent.

  • 04

    Backend reliability

    Failing background jobs, slow APIs and unreliable integrations investigated before committing to a rewrite.

How to start

Start From Your Situation

Every engagement starts small and ends with written outputs. Not 24/7 on-call support or managed operations.

Building something new?

01 System Design

For a new product or major capability, before serious development starts: clear system boundaries and an implementation direction.

You receive

  • System boundaries and main flows
  • Architecture decisions, written down with their trade-offs
  • An initial implementation direction for the team

Not included Full implementation, UI design and infrastructure provisioning.

Working around a difficult legacy system?

02 Architecture Review

For a team with a running system, often on .NET, that is unsure about its structure or where to take it next: what to improve, what to keep, and where to start.

You receive

  • Issues ranked by impact
  • Options for improvement, including what to keep
  • Recommended next steps and a first slice

Not included Executing the full migration or refactoring, which can follow as a separate engagement.

FAQ

Common Questions

Do we have to rewrite our .NET Framework application?

Usually not. I prefer migrating subsystem by subsystem while the system stays in use, as I did for five related subsystems moving to .NET 7.

Where does a modernization engagement start?

With an Architecture Review: issues ranked by impact, options including what to keep, and recommended next steps with a first slice.

Can you help with slow SQL Server queries or failing background jobs?

Yes. A Backend Reliability Assessment investigates the problem, tests hypotheses and gives corrective actions in priority order.
